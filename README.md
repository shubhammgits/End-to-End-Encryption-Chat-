# 🔐 SecureChat – Offline Encrypted Chat App in Python with GUI

**SecureChat** is a lightweight, privacy-focused chat application built entirely in **Python** with a custom **GUI interface**.
It works **100% offline** and utilizes **end-to-end encryption**, ensuring your messages remain private and never leave your device.

---

## 🚀 Features

* End-to-End AES Encryption
* Fully Offline – No Internet Needed
* Simple GUI (Built with Tkinter)
* No Account Creation, No Data Tracking
